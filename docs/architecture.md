# هندسة النظام: ERP-RMC
## معمارية الخدمات المصغرة (Microservices Architecture)

```
┌─────────────────────────────────────────────────────────────────────┐
│                         API GATEWAY (Port 3000)                      │
│              JWT Auth │ Rate Limiting │ Request Routing               │
└───────────┬───────────┬──────────────┬──────────────┬───────────────┘
            │           │              │              │
     ┌──────▼──┐  ┌─────▼───┐  ┌──────▼──┐   ┌──────▼──┐
     │FI-CORE  │  │  HCM    │  │PAYROLL  │   │RMC-OPS  │
     │:3001    │  │:3002    │  │:3003    │   │:3004    │
     └────┬────┘  └────┬────┘  └────┬────┘   └────┬────┘
          │            │            │              │
     ┌────▼────────────▼────────────▼──────────────▼────┐
     │              PostgreSQL (Port 5432)                │
     │         Shared DB - Schema Separated               │
     └───────────────────────────────────────────────────┘
          │            │            │              │
     ┌────▼────────────▼────────────▼──────────────▼────┐
     │         RabbitMQ Message Bus (Port 5672)          │
     │  Events: PayrollPosted │ TripCompleted │ InvoiceGenerated │
     └───────────────────────────────────────────────────┘
```

## تدفق البيانات - رحلة التوصيل الكاملة

```
أمر البيع → جدولة الإنتاج → تعبئة الشاحنة ← Batching Controller
     │              │                │
     ▼              ▼                ▼
فاتورة AR    أمر إنتاج        استهلاك مخزون
     │         (Job Order          (GL Entry)
     │          Costing)
     ▼
تسوية قيد     عمولة السائق → كشف راتب → قيد مالي
  AR-GL          (طبقة            عبر
                 الحساب          Symbolic
                 الرمزي)         Account
```

## مبادئ SAP Fiori الخمسة المطبقة

1. **Role-Based** - كل دور يرى واجهة مختلفة
2. **Responsive** - يعمل على الجوال والحاسوب
3. **Simple** - مهمة واحدة في كل شاشة
4. **Coherent** - نمط موحد في كل الوحدات
5. **Delightful** - تجربة مستخدم سلسة

## Floorplans المستخدمة

| النمط | الاستخدام |
|-------|----------|
| **List Report** | قوائم الفواتير، السائقين، أوامر البيع |
| **Object Page** | تفاصيل أمر البيع، ملف الموظف |
| **Worklist** | مهام المراجعة والموافقة |
| **Overview Page** | لوحة تحكم المدير |
